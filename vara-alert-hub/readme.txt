A clean updates and alerts theme for any site where posts change often: notices, announcements, results, releases and deals.

== Description ==

Vara Alert Hub puts "what changed" first. It is built for sites where posts are updated often, such as notice boards, job and exam alerts, release notes, deals, local news and community updates.

**Highlights**

* Text-first cards and lists that look complete without featured images
* "Updated" dates and NEW badges on every card and row
* An automatic colour for each category
* An optional "Last date" label and a short update note on each post
* A homepage with category tabs, featured cards and a latest updates list with page numbers
* Category, tag, author, date and search pages with filters, sorting and a list or grid view
* A live update board on the 404 page, with support for reduced motion
* A clean comment section with replies, an author badge and initials avatars
* Block patterns: important notice, important dates table, info card with button, how to apply steps, banner and three link cards
* Page templates: full width with title, full width without title (landing page), no title with sidebar, homepage layout and all updates
* Customizer options for the primary colour, sidebar position, featured images, labels, ticker, footer and the 404 page
* Translation ready, responsive and keyboard friendly, with a skip link and visible focus styles
* No external fonts, scripts or images. It uses the system font stack and plain JavaScript.

== Installation ==

1. In your WordPress admin, go to Appearance > Themes > Add New > Upload Theme.
2. Choose the theme zip file and click Install Now, then Activate.
3. Go to Appearance > Menus, create a menu and assign it to the Primary menu location.
4. Go to Appearance > Customize to choose a colour, a category for the featured cards and other options.

== Frequently Asked Questions ==

= How do I show featured cards on the homepage? =

Go to Appearance > Customize > Homepage and choose a category under "Category for featured cards". The most recently updated posts from that category appear as cards at the top of the homepage. Choose "None" to hide them.

= How do I use a custom homepage? =

Create a page and choose the "Homepage layout" template (or "Full width, no title (landing page)" if you want to build the page with blocks). Then go to Settings > Reading, choose "A static page" and select your page as the homepage.

= How do I add an update note or a last date to a post? =

Edit the post and open the "Update details" box in the editor sidebar. The update note appears at the top of the post. The last date appears as a "Last date" label on cards and in the post details. Leave a field empty to hide it.

= What does the NEW badge mean, and how long does it show? =

A post shows the NEW badge when it was published or updated recently. By default this is 3 days. You can change the number of days and the badge text in Appearance > Customize > Layout and display.

= Does the theme need featured images? =

No. The design is text first and looks complete without images. If you want images in cards and lists, go to Appearance > Customize > Layout and display and choose "Only when a post has an image" or "Always, with a placeholder". A post always shows its featured image on the post page when it has one.

= How do I change the colours? =

Go to Appearance > Customize > Colors and choose a primary colour. Category colours are assigned automatically. If you choose a very light primary colour, text on buttons may be hard to read.

= How do I move or hide the sidebar? =

Go to Appearance > Customize > Layout and display and choose Right, Left or Off for the sidebar. Add widgets under Appearance > Widgets. The sidebar appears on posts and on pages that use a sidebar layout. The homepage, archives and search results are always full width.

= How do I use the block patterns? =

Edit a post or page, click the + button, open the Patterns tab and choose the Vara Alert Hub category. You will find an important notice, an important dates table, an info card with a button, how to apply steps, a banner and three link cards.

= What page templates are included? =

Full width with title, full width without title (landing page), no title with sidebar, homepage layout and all updates. Choose one under Template in the page editor.

= How do I change the footer text? =

Go to Appearance > Customize > Footer. You can change the headings, the About text and the copyright text. If you add a widget to a footer column, it replaces the default content of that column.

= Can I hide the theme credit link in the footer? =

Yes. Turn off "Show the theme credit link" in Appearance > Customize > Footer.

= How do I show a scrolling ticker under the menu? =

Go to Appearance > Customize > Update ticker, enter the text and choose a label. Leave the text empty to hide the ticker. The ticker stays still for visitors who have reduced motion turned on in their device settings.

= Is the theme translation ready? =

Yes. All text uses the text domain vara-alert-hub, and a .pot file is included in the languages folder.

= Does the theme load anything from other websites? =

No. The theme loads no external fonts, scripts, styles or images. If avatars are enabled in Settings > Discussion, WordPress itself can load commenter photos from Gravatar. Comments show an initials circle when a commenter has no photo.

= Where can I get help? =

Use the theme's support forum on WordPress.org. You can also find the author on GitHub: https://github.com/Varaprasad-Jada
